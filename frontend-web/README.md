# Shanyraq Web (Next.js 15 / React 19)

Веб-приложение цифровой платформы **Shanyraq** (Шаңырақ), включающее:
1. **Панель управления УК / ОСИ (`/dashboard`)** — рабочее место управляющего, председателя ОСИ и диспетчера.
2. **Личный кабинет жителя (`/cabinet`)** — личный кабинет для собственников, квартирантов и членов семьи.

---

## 1. Доступ арендаторов и членов семьи (TASK-022)

### Модель доступа
- **Собственник (`OWNER`)**:
  - Полный доступ ко всем разделам кабинета.
  - Раздел «Жильцы квартиры» (`/cabinet/residents`) в навигации: просмотр списка жильцов, приглашение квартирантов и членов семьи по телефону, продление срока аренды, отзыв доступа, отмена ожидающих приглашений.
  - Лимит: максимум 5 жильцов на квартиру суммарно (TENANT + FAMILY_MEMBER + PENDING приглашения; собственники в лимит не входят).
- **Квартирант (`TENANT`)**:
  - Создание заявок на обслуживание, чат с диспетчерской, оформление гостевых пропусков и настройка PIN-кода шлагбаума.
  - Передача показаний индивидуальных приборов учёта воды и электричества.
  - Просмотр баланса лицевого счёта, начислений, истории платежей, скачивание квитанций и оплата.
  - Просмотр отчёта прозрачности ЖК.
  - Голосования ОСС: только ознакомление с повесткой и результатами (кнопка «Голосовать» заблокирована; API возвращает 403 Forbidden).
- **Член семьи (`FAMILY_MEMBER`)**:
  - Полный доступ к бытовым сервисам (заявки, пропуска, счётчики, бронирование, чат, SOS).
  - Лицевой счёт: отображение баланса без детализации финансовых начислений и оплат.
  - Голосования ОСС: только ознакомление.

### Управление сроком аренды и безопасность
- Поле `leaseEndDate` задаёт дату окончания действия прав. При наступлении даты доступ к сервисам блокируется автоматически.
- Планировщик `PropertiesSchedulerService` ежедневно отслеживает завершение аренды и уведомляет собственника за 7 дней.
- Мгновенный отзыв доступа собственником или сотрудником УК удаляет связь с помещением, отзывает все активные пропуска и инвалидирует JWT-токены жильца через инкремент `tokenVersion`.

## 2. Разработка и тестирование

# Установка зависимостей

npm run dev

npx tsc --noEmit

# Запуск юнит-тестов и проверки i18n
npm test
