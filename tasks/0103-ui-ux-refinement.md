# 0103 — Доработка UI/UX главной, заявок и SOS

Дата: 2026-10-16.

## Область проверки

Проверены исходники общего каркаса, главной по ролям, списка/карточки заявки, SOS, уведомлений и журнала смены. Изменения этого этапа затрагивают главную, заявки, SOS и словари ru/kk/en. Это проверка реализации интерфейса и исправления по коду; визуальная приёмка в браузере не завершена.

## Исправления

### Охрана и SOS

- Активные вызовы перенесены выше статистики: срочные действия доступны до графиков и истории.
- Убрана подпись LIVE и постоянная пульсация счётчиков; они не подтверждали актуальность соединения.
- Цветом и текстом разделены непринятые вызовы и работа сотрудника; рамки и тени облегчены. На главной охраны теперь также видны состояние и ответственный.
- На странице SOS число колонок учитывает фиксированную боковую панель: две карточки начиная с xl, три с 2xl. На узком экране действия располагаются вертикально. Кнопки обработки/закрытия диалога и поля дат получили достаточную высоту.
- История на телефоне представлена карточками вместо таблицы из семи колонок. Комментарии в настольной таблице больше не обрезаются. Даты истории учитывают выбранный язык.
- Первичная ошибка загрузки не превращается в сообщение «все вызовы обработаны». Повторное обновление не заменяет всю страницу спиннером.
- Ошибка статистики показана с повторной попыткой, отсутствующие данные обозначены тире. График при ошибке скрыт; во время загрузки показано состояние ожидания.
- При смене периода предыдущий запрос отменяется; устаревший ответ не перезаписывает новые данные. Запросы отменяются при уходе со страницы.
- Поля периода связаны с labels, проверяется порядок дат; экспорт недоступен при некорректном периоде.
- «Среднее время реагирования» переименовано в «Среднее время обработки», поскольку API считает интервал до завершения, а не до принятия.

### Заявки

- Добавлены отдельные фильтры назначенных, выполненных и отклонённых заявок. Все шесть статусов фильтруются точно: «В работе» больше не включает назначенные, «Закрытые» — выполненные и отклонённые.
- Фильтры переносятся на несколько строк, без горизонтального прокручивания панели. Показано число найденных заявок.
- Поиск игнорирует пробелы по краям введённой строки.
- Длинные комментарии и их заголовки переносятся; сохранены переводы строк. Кнопка отправки ответа удобнее на узком экране.
- Ошибки списка имеют role=alert.

## Ограничения и остаток приёмки

Локальный frontend был запущен на порту 3001. Встроенный браузер сначала получил ERR_CONNECTION_REFUSED до запуска сервера, затем заблокировал обращение к вкладке страницы ошибки по URL policy. Обход ограничений через другой браузер/порт/средство не предпринимался. Созданный для проверки сервер остановлен.

Скриншоты, реальные ширины 360/390/768/1440, поведение меню и диалогов с клавиатуры, переводы при максимальной длине и полный визуальный проход финансов/доступа/остальных разделов остаются непроверенными. Эти изменения нельзя считать доказательством полного визуального соответствия или завершённости всего UI/UX.
