# 0098 — Веб-панель: навигация, адаптивность и работа с заявками

Дата: 2026-10-16.

## Изменения

- Sidebar разделён на обзор, работу с жильцами, дом/доступ и управление. Пункты по-прежнему фильтруются по ролям.
- На ширине менее 1024 px используется нативное модальное меню с Escape, удержанием фокуса, блокировкой фоновой прокрутки и возвратом фокуса. На desktop меню имеет собственную прокрутку.
- Шапка и поиск адаптивны; карточки главной переходят от одной к двум и четырём колонкам. Появились skip-link, общий focus-visible и поддержка reduced-motion.
- Поиск различает ошибку и пустую выдачу, игнорирует устаревшие ответы; суперадминистратор явно выбирает ЖК. Уведомления помещаются в мобильный viewport, поддерживают Escape и клавиатурное открытие элементов, показывают ошибку загрузки и повтор.
- Поля входа и восстановления пароля связаны с label, добавлены autocomplete и объявление ошибок/успеха для экранного диктора.
- Главная больше не подставляет 140 квартир/площадь и не показывает фиктивные 14 минут ответа или отсутствие сбоев. Завершённое собрание не выдаётся за активное; при ошибке загрузки показатели скрыты за тире и выводится предупреждение.
- Заявки: мобильные карточки вместо широкой таблицы, более читаемая desktop-таблица, крупные фильтры, отдельные состояния ошибки/пустого поиска и сброс фильтров.
- Диалог заявки использует общий native Dialog: доступное название, удержание/возврат фокуса, Escape, прокрутка внутри окна, адаптивные поля и действия.
- Запоздавший ответ загрузки/обновления заявки не открывает закрытый диалог и не заменяет другую открытую заявку. Повтор загрузки после ошибки сохраняет черновик комментария.
- Статусы заявок сверены с Prisma RequestStatus: отображаются ASSIGNED/REJECTED, несуществующее действие CANCELLED заменено на REJECTED. Назначенные заявки включены в фильтр «В работе», отклонённые — в завершённые. Назначение исполнителя этим этапом не реализовывалось.
- Новые сообщения переведены на ru/kk/en.

## Проверки и ограничения

- Production build после изменений диалога и уведомлений: успешно, 26 страниц.
- TypeScript и git diff --check: успешно; наличие новых ключей переводов проверено.
- На предыдущем шаге оболочка проверена в браузере на изолированных синтетических данных: 390 px — нет горизонтальной прокрутки, меню открывается/закрывается, Escape возвращает фокус; 1440 px — desktop-оболочка. Проверено отдельное сообщение об ошибке поиска.
- Повторная визуальная приёмка новых карточек и диалога 16 октября заблокирована политикой доступа браузерного инструмента. Скриншоты итогового состояния не получены; эти изменения не считаются визуально принятыми.
- Демонстрационный API находился вне репозитория, слушал только 127.0.0.1 и не обращался к настоящей БД. Временные серверы остановлены; production-конфигурация API не менялась.
