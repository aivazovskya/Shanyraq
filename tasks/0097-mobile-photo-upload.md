# 0097 — Загрузка фотографий в мобильном приложении

Дата: 2026-10-15.

## Реализация

- Общий PhotoAttachments вместо фиктивных URL в создании заявки, показаниях счётчика, объявлениях и чате жильца.
- Системная камера/галерея через expo-image-picker; разрешение камеры запрашивается по действию пользователя. Для отказа есть переход в настройки, отмена выбора ничего не загружает.
- Нормализация изображения в JPEG через expo-image-manipulator, длинная сторона до 2048 px, качество 0.85. Проверка известного размера исходника: до 15 МБ; сервер сохраняет ограничение multipart 15 МБ и проверку содержимого файла.
- До пяти фото в заявке/объявлении, одно фото в показании/сообщении. Предпросмотр, удаление из формы, индикатор подготовки/загрузки, повтор неудачной загрузки без повторного выбора.
- Форма получает URL только после успешного POST /uploads. Во время загрузки отправка формы и повторный выбор заблокированы. При уходе с экрана HTTP-загрузка отменяется; закрытие модального окна показаний размонтирует компонент.
- UploadsApi использует 60-секундный тайм-аут и AbortSignal.
- Тексты ru/kk/en. Expo config plugin задаёт назначение доступа к камере/фото и отключает разрешение микрофона.
- S3_PUBLIC_BASE_URL позволяет выдавать клиенту внешний адрес, оставляя серверные запросы к внутреннему S3 endpoint. Настройка добавлена в шаблон и production compose. Права бакетов не изменены; presigned POST продолжает использовать существующий S3 endpoint.

## Проверки

- Mobile typecheck — успешно.
- UploadsService — 11 тестов успешно, включая внешнюю ссылку при внутреннем S3 endpoint.
- Новые переводы присутствуют во всех трёх языках; git diff --check без ошибок.
- Expo export Android/iOS — успешно: оба Hermes-пакета собраны в mobile/dist/audit (игнорируемый каталог). Первый запуск в песочнице завершился ошибкой Hermes; повтор вне песочницы прошёл. Это не нативная APK/IPA-сборка.

## Приёмка на устройстве — ещё не выполнена

Нужны рабочий API, S3 и авторизованный способ доставки медиа, доступные с телефона. Сам S3_PUBLIC_BASE_URL не предоставляет доступ к приватному бакету. Не открывать бакет документов публично ради этой настройки.

Проверить: камера с разрешением/отказом; отмена галереи; JPEG/HEIC; слишком большой файл; обрыв сети и повтор; уход с экрана во время загрузки; удаление/лимит вложений; отправка формы и просмотр фото с другого аккаунта с соответствующими правами. Нативное приложение требуется пересобрать после добавления модулей и config plugin.

Удаление фото из формы не удаляет уже загруженный объект из S3. Очистка неиспользованных загрузок требует отдельного серверного жизненного цикла объектов.

Документация API: [Expo ImagePicker](https://docs.expo.dev/versions/latest/sdk/imagepicker/), [Expo ImageManipulator](https://docs.expo.dev/versions/latest/sdk/imagemanipulator/). Использованы совместимые с установленным SDK версии, выбранные expo install.
